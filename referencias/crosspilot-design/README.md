# Crosspilot · diseño (prototipo interactivo)

Prototipo de la pantalla principal de Crosspilot, copiloto de venta cruzada para el ejecutivo de negocios.

- `Crosspilot.dc.html`: prototipo completo (agenda, negociación entre agentes, aprobación, ficha, post-visita y perfil del cliente). Datos sintéticos y respuestas predefinidas, sin API.
- Para verlo: abrir el archivo en Claude Design, o servirlo con `npx serve` desde esta carpeta.
- Spec de referencia: `Crosspilot_export_chat_para_Claude_Design.md`.
- Implementación objetivo: Streamlit (notas de componentes dentro del prototipo, tweak "Mostrar notas de Streamlit").
